# assets/

`icon.png`, `adaptive-icon.png`, `splash.png` şu an **placeholder** (düz renk) dosyalardır.
Yayın öncesi gerçek marka görselleriyle değiştirin:

- `icon.png` — 1024×1024, kenar boşluğu bırakın (iOS köşeleri yuvarlar)
- `adaptive-icon.png` — 1024×1024, Android adaptive foreground (güvenli alan merkez %66)
- `splash.png` — merkezde logo, arka plan `#17130F`

Renkler `app.json` içindeki `backgroundColor` ile eşleşmelidir.
